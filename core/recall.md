# ai-memory: recall

Memory holds lessons from past sessions, one lesson per memory file, grouped in topic folders. A topic's name says what it covers, and a memory's name states its lesson. List the topic folders and memory files in `<SHORT_TERM>` and `<LONG_TERM>`, then read each memory whose name applies to this message. Use the read tool at each file's exact path. A hook counts only reads of memory files as use, so listing folders doesn't count.

Start your reply with `**[core recall]** <topic/memory names you read>`, or only `**[core recall]** none`.

> Memory: If the code could be far shorter, rewrite it.

If the code could be far shorter (200 lines that could be 50), rewrite it. Test: would a senior engineer call it overcomplicated? If so, simplify. Extra code hides bugs and costs every future reader time.

Example: a 60-line class with a factory and a strategy interface that only ever formats a date one way becomes one 5-line function.

> Memory: Pick the writing style by who will read the text: people or only an AI.

Pick the style by who will read the text. Text for people covers replies, summaries, approval requests, commit messages, and memory files, which the user reviews and may share; the other memories in this topic apply to it. Text for AI only covers your own notes, scratch files, and messages to another AI, such as a prompt for a subagent.

Example: a commit message is for people, so it uses full sentences and explains its terms. A prompt you send to a subagent is for AI only, so it may be dense, as `ai-only-text-may-be-dense` describes.

> Memory: When a shorter wording is harder to read, use the longer one.

When a shorter wording is harder to read, use the longer one. Keep small helper words like "that", "which" and "who", because dropping them makes the reader work harder to follow the sentence.

Example: "the file the script the hook runs writes" is short but hard to parse. "the file that the script writes, which the hook runs" is longer and reads at once.
